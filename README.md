# MotionCanvas Web

A modern, full-featured 2D animation and drawing studio ported to React and Vite with HTML5 Canvas.

## Features
- **Drawing Canvas & Tools**: Brush, Eraser, Line, Rectangle, Ellipse, Lasso Selection, Flood Fill, and Eyedropper.
- **Brush Engines**: Pencil, Pen, Marker, and Airbrush with stabilization, streamline smoothing, spacing, pressure dynamics, taper, and alpha lock.
- **Animation Timeline**: Multi-frame timeline with variable frame rate (8, 12, 24 FPS), frame hold control, ping-pong playback loop, frame duplication, and onion skinning.
- **Multi-Layer System**: Layer reordering, individual layer visibility, opacity control, and clipping mask support.
- **Vector & Node Editing**: Bezier handle editing, interactive control nodes, add/delete/respace nodes, and shape regularizer (Quick Shape).
- **Rigging & Weight Paint**: 2D bone joints, parent-child hierarchies, weight paint posing, and interactive mesh sculpt modes (Grab, Push, Smooth, Pinch).
- **Grids & Perspective Guides**: 2D grid, Isometric grid, and 1-Point, 2-Point, and 3-Point perspective vanishing point guides with precision angle and ray snapping.
- **Export & Storage**: Export high-resolution PNGs, animated GIFs, and save/load `.motioncanvas` project zip packages.
